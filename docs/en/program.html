Reference manual

Features of the main program of Superconducting-Toolkit, sctk.x, are as follows:
  • Compute the Coulomb interaction matrix $K^{el}_{n {\bf k} n' {\bf k}'}$ as a preprocess. This program uses Kohn-Sham orbitals generated by QE.
  • Solve the gap equation and obtain the superconducting gap function $\Delta_{n {\bf k}}$.
  • Solve the gap equation and obtain the superconducting transition temperature with the bisection method.
  • Perform non-SCF calculation for generating files readable by FermiSurfer.
  • Perform non-SCF calculation for obtaining quasi particle density of states.
  • Perform non-SCF calculation for obtaining ultrasonic attenuation coefficient (experimental).
Also, there is a script twingrid to generate the double k-point grid where Kohn-Sham orbitals for the calculation of the Coulomb interaction are computed.

Usage


$ mpiexec options PATH/sctk.x -in input_file

Data files

The following files are read/written by sctk.x:

{prefix}.xml

It contains information about lattice constant, etc. It is generated by pw.x.

{prefix}.a2Fsave

It contains the Kohn-Sham energy, information of k mesh, and symmetry operations. It is generated by pw.x with la2f=.true.

{prefix}.save/wfc*.dat

It contains Kohn-Sham orbitals at each k point. * should be the index of k point. It is generated by pw.x.

{prefix}.vel*

It contains coefficients of the Chebyshev interpolation of the screened Coulomb interaction at each q point. * should be the index of q point. It is generated by sctk.x with calculation="kel".

{prefix}_ph0/{prefix}.q_*/{prefix}.elph*

It contains electron-phonon interactions and phonon frequencies at each q point. * should be the index of q point. It is generated by ph.x with electron_phonon="scdft_input".

{prefix}_lambda.frmsf, {prefix}_mu.frmsf

Data files for FermiSurfer for displaying the mass-renormalization factor $\lambda_{n {\bf k}}$ on the Fermi surface. It is generated by sctk.x with calculation="lambda_mu_k".

{prefix}.scgap

It contains the superconducting gap functions $\Delta_{n {\bf k}}$, associated Kohn-Sham energy $\xi_{n {\bf k}}$, integration weights, band indices, k-indices, and the renormalization $Z_{n {\bf k}}$. It is generated by sctk.x with calculation="scdft".

{prefix}.qpdos

First column: quasiparticle energy (meV unit), Second column: quasiparticle density of states (Ry-1 unit). It is generated by sctk.x with calculation="qpdos".

{prefix}_delta.frmsf, {prefix}_Z.frmsf

Data files for FermiSurfer for displaying the superconducting gaps $\Delta_{n {\bf k}}$ and the renormalization $Z_{n {\bf k}}$ on the Fermi surface. It is generated by sctk.x with calculation="deltaf".

Type of calculation

We can specify the type of calculation by inputting the following string into the parameter calculation.

kel : Screened Coulomb interaction / spin-fluctuation

The following files must be put on the directory where the program runs.
  • {prefix}.xml
  • {prefix}.a2Fsave
  • {prefix}.save/wfc*.dat
The following files are generated in the directory where the program runs.
  • {prefix}.vel*

lambda_mu_k : Electron-phonon parameter at each orbital

The following files must be put on the directory where the program runs.
  • {prefix}.xml
  • {prefix}.a2Fsave
  • {prefix}_ph0/{prefix}.q_*/{prefix}.elph*
  • {prefix}.vel*
The following files are generated in the directory where the program runs.
  • {prefix}_lambda.frmsf, {prefix}_mu.frmsf

scdft : SCDFT calculation at specific temperature

The following files must be put on the directory where the program runs.
  • {prefix}.xml
  • {prefix}.a2Fsave
  • {prefix}_ph0/{prefix}.q_*/{prefix}.elph*
  • {prefix}.vel*
The following files are generated in the directory where the program runs.
  • {prefix}.scgap

scdft_tc : Calculation of transition temperature with bisection method

The following files must be put on the directory where the program runs.
  • {prefix}.xml
  • {prefix}.a2Fsave
  • {prefix}_ph0/{prefix}.q_*/{prefix}.elph*
  • {prefix}.vel*
The following files are generated in the directory where the program runs.
  • {prefix}.scgap

qpdos : Quasi-particle density of states

The following files must be put on the directory where the program runs.
  • {prefix}.xml
  • {prefix}.a2Fsave
  • {prefix}_ph0/{prefix}.q_*/{prefix}.elph*
  • {prefix}.vel*
  • {prefix}.scgap
The following files are generated in the directory where the program runs.
  • {prefix}.qpdos

deltaf : Output FermiSurfer file of gap function

The following files must be put on the directory where the program runs.
  • {prefix}.xml
  • {prefix}.a2Fsave
  • {prefix}_ph0/{prefix}.q_*/{prefix}.elph*
  • {prefix}.vel*
  • {prefix}.scgap

twingrid.x

This script generates the double k-point grid for pw.x. The output orbitals of this pw.x run are used by sctk.x with calculation="kel".

Usage


$ bash PATH/twingrid.x nk1 nk2 nk3 dk1 dk2 dk3 >> input_file_for_pw
nk1, nk2, nk3 indicate the number of k points along each reciprocal lattice vector. dk1, dk2, dk3 are 0 or 1, and specify whether the grid is shifted by a half grid (1) or not (0) along each reciprocal lattice vector.
Typically dk1 = dk2 = dk3 = 1 is used. For hexagonal or simple tetragonal lattices, it is recommended to set 1 only along the z axis and 0 for the others.

Standard output

The standard output is as follows: 

K_POINTS crystal
Total_number_of_k
k_vector1 1.0
k_vector2 1.0
k_vector3 1.0
  :
It generates two k grids; the first one contains the $\Gamma$ point, and the other is translated by a half grid. In the above usage, the standard output of this utility is redirected to the end of the input file of pw.x.
